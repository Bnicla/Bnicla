## What I'm building

**VAI** ([spokesbot.ai](https://spokesbot.ai)): an AI twin that answers interview questions the way I would, in first person, from my own stories.
- Text: Claude, through the Anthropic API
- Voice: ElevenLabs Conversational AI with a clone of my voice
- Video: Tavus, with ElevenLabs as the voice layer
- Runs on Vercel serverless functions. Every update is checked against my real answers, so it doesn't invent anything.

**Kairos** (private): my agentic job-search system, built on Claude Code and a custom MCP server.
- Sources roles every morning across ~15,000 company job boards, screened by Claude, with a fine-tuned model running in shadow
- Scores each role against my real experience and tailors résumés that must pass grounding and style checks: every claim traces to a source, every number to a confirmed metric
- A Next.js dashboard tracks the whole pipeline, from sourced role to offer
- Codex reviews high-stakes work as an outside adversary

**[jubo](https://github.com/Bnicla/jubo)**: a privacy-first AI assistant that runs on-device on iOS, using MLX.

**[My Scores](https://my-scores-one.vercel.app)**: a multi-sport scores app for following my teams and players across football, NBA and NFL. Weekly calendar, live scores, player ratings, a spoiler-free mode for games I haven't watched yet, and sync across devices. React and TypeScript on Vercel.
